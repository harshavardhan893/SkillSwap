# SkillSwap – Student Skill Exchange Platform

**Learn Together. Grow Together.**

## 1. Project Overview

SkillSwap is a web-based platform that allows college students to exchange skills and knowledge without monetary transactions.

Students can register, create profiles, list the skills they can teach, and choose the skills they want to learn. The platform helps students find suitable learning partners and exchange knowledge through a simple request system.

## 2. Problem Statement

Many students have useful skills but do not always have access to affordable learning opportunities or suitable people to learn from.

SkillSwap addresses this problem by connecting students who can teach with students who want to learn, encouraging collaborative and peer-to-peer learning.

## 3. Project Objectives

- Encourage knowledge sharing among students.
- Provide a platform for peer-to-peer learning.
- Help students discover suitable learning partners.
- Make skill development accessible without monetary transactions.
- Build collaboration and communication among students.

## 4. Main Features

- **Student Registration:** Students can create accounts.
- **Login and Logout:** Secure account access.
- **Student Directory:** Browse registered students and their skills.
- **Skill Matching:** Find students with complementary learning interests.
- **Exchange Requests:** Send learning requests to other students.
- **Request Management:** Accept or reject incoming requests.
- **Edit Profile:** Update name and skill information.
- **Password Recovery:** Reset forgotten passwords.
- **Student Feedback:** Submit ratings and written feedback after accepted exchanges.
- **Student Reviews:** View feedback and ratings submitted by students.
- **Dashboard:** View profile details, student count, matches, and exchange statistics.

## 5. Technologies Used

| Technology | Purpose |
|---|---|
| HTML | Website structure |
| CSS | Website design and styling |
| JavaScript | Interactive functionality |
| Supabase | Backend and database |
| Supabase Authentication | User registration and login |
| Supabase PostgreSQL | Store student and exchange information |
| Visual Studio Code | Development environment |
| Live Server | Run the website locally |

## 6. Database Tables

The project uses the following main database tables:

- **students:** Stores student profiles and skill information.
- **skills:** Stores student skill details.
- **exchange_requests:** Stores learning exchange requests and their statuses.
- **reviews:** Stores ratings and written feedback after exchanges.

## 7. How the Platform Works

1. A student registers and logs in.
2. The student creates a profile with college and skill details.
3. The student browses the student directory.
4. The platform displays suitable skill matches.
5. The student sends an exchange request.
6. The receiving student accepts or rejects the request.
7. After an accepted exchange, students can submit ratings and written feedback.
8. Students can view reviews on the reviews page.

## 8. How to Run the Project

1. Download or clone the project folder.
2. Open the folder in Visual Studio Code.
3. Ensure the Supabase project is configured in `supabase.js`.
4. Install the Live Server extension if it is not already installed.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. Register or log in to use the platform.

**Note:** The Supabase project must remain active and its authentication and database configuration must be available for the application to work.

## 9. Expected Outcome

SkillSwap provides a collaborative learning environment where students can share their knowledge, discover learning partners, exchange skills, and improve their abilities through peer-to-peer learning.

## 10. Conclusion

SkillSwap demonstrates how web technologies and backend services can be used to create a student-focused learning platform. It encourages students to become both teachers and learners while building a supportive learning community.
